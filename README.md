# AnalogyAI

AI-powered analogy generation and explanation web app built with Python and Streamlit.
This project helps users understand complex concepts using intelligent analogies generated through Generative AI models.

---

## Visit app
https://anlogy-ai.streamlit.app/

## Features

* Generate analogies for technical and non-technical concepts
* Interactive Streamlit user interface
* AI-powered responses using Gemini API
* Lightweight and beginner-friendly architecture
* Fast local deployment
* Easy to customize and extend

---

## Tech Stack

* Python
* Streamlit
* Google Gemini API
* dotenv
* Requests

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Ri8shi/AnalogyAI.git
```

### 2. Navigate to Project Folder

```bash
cd AnalogyAI/analogyinpy
```

### 3. Create Virtual Environment

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file in the root directory.

```env
GOOGLE_API_KEY=your_api_key_here
```

Get your API key from Google AI Studio.
https://aistudio.google.com/api-keys

---

## Run the Application

```bash
streamlit run app.py
```

The app will run locally at:

```bash
http://localhost:8501
```
